This set tests careful handling of letters: putting words in order, building words from letters, and spelling.

## Dictionary order

Compare words one letter at a time, from the left.

1. Look at the first letters. The word whose letter comes earlier in the alphabet comes first.
2. If the first letters match, compare the second letters, then the third, and so on.
3. If one word is the start of another, the shorter word comes first: *pin* comes before *pinch* and *pine*. (Between those two, the fourth letters are c and e, so *pinch* comes before *pine*.)

## Worked example

*Arrange in dictionary order: Rabbit, Rack, Raft, Radish.*

All start with *ra*. Third letters: b, c, f, d. Alphabetical: b, c, d, f. So the order is **Rabbit, Rack, Radish, Raft**.

## Making words from a word

Write the big word's letters with a count for each. For DICTIONARY: D, C, T, O, N, A, R, Y once each, and I twice. Then check each option letter by letter.

The common trap is a word whose letters are all present but one letter is needed **twice** when the big word has it only once.

## Jumbled letters

Start with likely pairs, such as *ch*, *th*, *ng* or *er*, and likely endings, such as *-ing*, *-er* or *-al*. Then fit the rest around them. Always check that every letter is used exactly once.

## Spelling

| Pattern | Examples |
|---|---|
| i before e, except after c | believe, field; ceiling, deceit |
| double letters to remember | accommodate (double c, double m), committee, address, tomorrow (double r only) |
| words that sound alike | stationary (not moving), stationery (paper and pens) |
