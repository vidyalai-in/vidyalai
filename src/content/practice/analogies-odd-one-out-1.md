An analogy compares two pairs: "A is to B as C is to D", written **A : B :: C : D**. You find the link between the first pair, then pick the word that has the same link with C.

## Method

1. Say the link between the first pair as a sentence: "A carpenter **uses** a saw."
2. Put the third word into the same sentence: "A tailor **uses** a ...".
3. If more than one option fits, make your sentence more exact. "Uses as a tool" rules out cloth and thread, which are materials.
4. Keep the order. Material : product is not the same as product : material.

## Common links

| Link | Example |
|---|---|
| worker : tool | farmer : plough, painter : brush |
| worker : what is made | weaver : cloth, poet : poem |
| part : whole | finger : hand, key : keyboard |
| animal : young one | cat : kitten, lion : cub, goat : kid |
| animal : home | lion : den, bird : nest, pig : sty |
| raw material : product | sugarcane : jaggery, wood : paper |
| instrument : what it measures | odometer : distance, ammeter : current |

## Worked example

*Wool : Sweater :: Clay : ?   (Potter, Pot, Mud, Wheel)*

Link: "A sweater is made from wool." Try it with clay: "A ... is made from clay." **Pot** fits. *Potter* is the person and *wheel* is the tool. *Mud* is close to clay itself.

## Trap

The most tempting wrong option is usually connected to the third word but by a *different* link, often the tool, the material or the place.
