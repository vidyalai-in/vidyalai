## Issues found
- "Output tokens cost 3-5x input tokens" is low. October 2026 list prices: every current Claude model is exactly 5x (e.g. Sonnet 5.5 $2/$10, Haiku 5.5 $0.10/$0.50, Opus 5.5 $4/$20); OpenAI's current lineup is 5-8x (gpt-6 family 5x, gpt-5.4/5.5/5.6 about 6x, gpt-5/5.1/5.2 and gpt-5-nano 8x; older o3/gpt-4.1 4x).
- Prompt caching: only the 5-minute write price (1.25x) was given; the 1-hour TTL write is 2x. Cache reads are no longer uniformly 0.1x: 0.05x on Opus 5.5 and Sonnet 5.5, 0.025x on Fable 5.1 and Mythos 5.1.
- "OpenAI applies discounted caching automatically" is still true, but GPT-5.6+ now bills cache writes at 1.25x and reads at 0.1x (0.05x for GPT-6.1 Sol), 30-minute retention, 1,024-token minimum.
- "Price gaps between model tiers are 5-30x" is stale: adjacent tiers are now about 2-20x (Opus 5.5 vs Sonnet 5.5 2x; Sonnet 5.5 vs Haiku 5.5 20x) and top-to-bottom about 100x (Fable 5.1 vs Haiku 5.5; gpt-6-astra vs gpt-6-luna).
- "Input is usually 70-90% of tokens ... so this alone can halve the bill": with a 5x output price, 85% input tokens is only about 53% of spend; caching 80% of input cuts the bill about 38%, not 50%. Halving needs input to dominate spend.
- "30% to 70% utilization roughly halves cost per token": actually 30/70 = 0.43, i.e. more than halves. Clarified.
- Worked example: routing 65% to a 10x-cheaper tier is a 58.5% cut before escalations; -55% is right only with an escalation allowance (now shown). Final figure is $206.6k (79%), not "about $205k, ~80%".
- Interview framing: "I build", "Pitfalls interviewers probe", "Clarify first", "Measuring success".
- Fake header row with bold markers and `\~`, `\<` escapes in the original tables.
