## Issues found
- Table fake header rows; `\~` escapes.
- First-person voice and interview framing.
- "A ~100M-param model on one GPU reranks 100 passages of ~256 tokens in ~30-100 ms": verified by FLOPs (2 x 100M x 25,600 tokens ~ 5.1 TFLOP; at 50-150 sustained TFLOPs -> 34-102 ms). Correct for data-center GPUs; added the calculation and the scaling for 22M/560M models.
- "$1-2/hr GPU at 20-50 QPS -> cents per 1,000 queries": $1/(50 x 3,600) to $2/(20 x 3,600) = $0.006-0.03 per 1,000 queries. Correct (assumes full utilization); made explicit.
- "Drop k from 20 to 8 (~6k fewer tokens)": 12 chunks x ~500 tokens = 6k. Consistent. Added illustrative $ savings (~$6 per 1,000 queries at $1/M), 200-1,000x the reranker cost.
- "+2-3 point nDCG@10 gain detectable on ~1,000 queries": verified with an assumed per-query difference SD of 0.25 (SE 0.008, 95% CI +/-1.6 points).
- "512-token limit" stated as a property of small cross-encoders in general; true for classic BERT/MiniLM cross-encoders but some newer rerankers accept longer inputs. Reworded to "often" and "check the limit".
- "Cuts tokens and cost by 30-50%" unsourced; labeled as plausible.
- Product names (Cohere Rerank, Voyage AI, bge-reranker, monoT5) kept without version numbers. Cohere docs (checked Oct 2026) list Rerank 4.0 and 3.5 models; no versions asserted in the post.
- Contextual-retrieval rerank gain (49% -> 67%) verified; added that Anthropic reranked top 150 -> 20.
