## Issues found
- Tables exported with an empty header row and bold first row; `\~`, `\<` escapes throughout.
- First-person voice ("I'd build", "I'd sample") and "What a principal would add" / "Pitfalls interviewers probe" framing.
- Chunk count: 25B tokens / 10M docs = 2,500 tokens/doc; at 300-800 tokens/chunk that is ~3-8 chunks/doc = 30-80M chunks, not "5-10 chunks/doc, 50-100M". 100M is kept as a capacity-planning figure with headroom.
- Vector sizing verified: 100M x 1024 x 4 B = 409.6 GB; 100M x 512 x 1 B = 51.2 GB; binary 1024-bit = 12.8 GB, 512-bit / 64-byte PQ = 6.4 GB. All correct. Clarified that rescoring vectors live on SSD.
- Daily volume: 50 x 86,400 = 4.32M queries/day; x 12k = 51.8B tokens/day (original said ~50B). Correct arithmetic, but 50 QPS was defined as peak, so this is an upper bound; stated explicitly.
- "Generation dominates by more than 10x": at an illustrative $1/M input tokens, ~$52k/day vs a few thousand $/month for retrieval, so the claim is conservative. Kept, with a worked example clearly labeled illustrative.
- Embedding throughput "25B tokens on a few dozen GPUs is about a day": requires ~290k tokens/s. Plausible only for a ~7B LLM-based embedder (~5-10k tok/s/GPU -> 30-60 GPUs); a ~300M encoder needs only a handful of GPUs. Rewritten as a model-size-dependent worked example (FLOPs estimate: ~2 x params per token).
- HNSW "RAM-heavy (~1.5-2x vector size)": Faiss gives HNSW memory as d*4 + M*2*4 bytes/vector; for 1024-d fp32, M=32 that is ~6% overhead, ~50% only for 512-byte compressed vectors. Corrected.
- Contextual Retrieval figures verified against Anthropic: 5.7% -> 3.7% (35%), -> 2.9% (49%), -> 1.9% (67%), $1.02 per million document tokens with Claude 3 Haiku and prompt caching (Sept 2024). Added absolute rates and model/assumption context; computed ~$25k one-time for 25B tokens.
- Semantic cache "often 10-30% hit rate" and fine-tuning "+5-15 points" are unsourced; reframed as illustrative/plausible ranges.
- TTFT budget: worst-case pre-generation stages + TTFT = 1,400 ms, within the 1.5 s target; added the check and the caveat that p95s do not add.
- HNSW paper year was missing (2016 arXiv).
