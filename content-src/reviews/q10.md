## Issues found
- "Per-call schema validity (easy, about 99%+ with strict mode)" and "Schema-valid calls >= 99.5% (strict mode makes this nearly 100%)": Claude's `strict: true` uses grammar-constrained sampling and guarantees schema-conforming input and a valid tool name, so it is 100% by construction; business-rule validation is still needed.
- "τ-bench showed pass^8 far below pass^1" was vague; the abstract gives gpt-4o < 50% success and pass^8 < 25% in retail (2024).
- "Keep responses to about 1-5k tokens max" had no anchor; Anthropic's tool-writing post says Claude Code caps tool responses at 25,000 tokens by default. Kept the target as guidance, added the cap as a reference point.
- "With more than about 20-30 tools, use dynamic tool loading" now has a concrete mechanism (Anthropic's tool search tool, built for thousands of tools).
- BFCL is at V4 (agentic evaluation), last updated 2026-04-12.
- First-person voice, "Clarify first", "Pitfalls interviewers probe"; fake header row.
